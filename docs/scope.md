## Higher-derivative coverage at a glance

Which cubic (FC3) and quartic (FC4) routes exist, by boundary condition and by
occupation regime. ✅ = implemented and gated; ❌ = returns an explicit `Err`
(never a silent wrong number). All names are Rust entry points; see
[rust-api.md](rust-api.md) for signatures and [limitations.md](limitations.md)
for the residuals.

### FC3 — `∂³E/∂R³`

| Route | Molecular | PBC Γ | PBC k-mesh |
| --- | --- | --- | --- |
| **Analytic, `T = 0`** | ✅ `third_derivative_analytic{,_dense,_vector,_block}` | ✅ `pbc_gamma_third_analytic_{vector,dense,block}` | ✅ `pbc_kpoint_third_analytic_{vector,dense,block}` |
| **Analytic, finite `T`** | ✅ `third_derivative::finite_t::{directional_third_finite_t, third_derivative_finite_t_dense, third_derivative_finite_t_block}` | ❌ rejected | ❌ rejected |
| **Seminumerical** (FD of the analytic Hessian; smearing OK) | ✅ `third_derivative_seminumerical_{dense,vector,block}` | ✅ `pbc_third_derivative_seminumerical_{dense,vector}` | ✅ `pbc_kpoint_third_derivative_seminumerical_{dense,vector}` |

The two analytic periodic paths share one assembly, so they share its open
`~1e-7` absolute residual against the seminumerical reference; the Γ-named entry
points additionally reject a non-Γ mesh (they are the cheap specialisation, not
a subset of the k-point path's coverage).

### FC4 — `∂⁴E/∂R⁴`

| Route | Molecular | PBC Γ / k-mesh |
| --- | --- | --- |
| **Analytic, `T = 0`, directional** | ✅ `directional_fourth_derivative` — **no DOF cap** | ❌ not implemented |
| **Analytic, `T = 0`, full tensor** | ✅ `fourth_derivative_analytic_{dense,block}` | ❌ not implemented |
| **Analytic, finite `T`** | ✅ `third_derivative::finite_t::{directional_fourth_finite_t, fourth_derivative_finite_t_dense, fourth_derivative_finite_t_block}` | ❌ not implemented |
| **Seminumerical** (central FD of the analytic FC3) | ✅ `directional_fourth_seminumerical` | ❌ not implemented |

There is **no periodic FC4** at any temperature. Note the module split: the
finite-temperature FC4 lives in `third_derivative::finite_t` beside the finite-T
FC3, not under `fourth_derivative` — the strict `fourth_derivative::assemble`
routes are integer-occupation only and reject smearing.

| Parametrization | The official GFN1-xTB parameter files are **bundled** (`third_party/xtb`, verbatim from `grimme-lab/xtb@2b5cd48`, LGPL-3.0-or-later) — nothing to download. `Gfn1Parameters::resolve` picks explicit spec > `GFN1_XTB_PARAM` > builtin; `builtin` / `builtin:si` select the bundled GFN1-xTB / GFN1(Si)-xTB sets. | SCC energy | Gamma (real path) and explicit Monkhorst-Pack k-points (Bloch path). |
| SCC convergence | Charge mixing (linear / Broyden), Pulay **CDIIS**, second-order **Newton** (transition-charge susceptibility, FD-verified Jacobian), and virtual **level shifting**; selectable via `SccAccelerator` + `level_shift`. With the multipole correction on, the atomic dipole/quadrupole (and octupole) moments are mixed **jointly with the charges** in the Broyden vector (tblite-style multipole SCF) for robust convergence. With the experimental Fock exchange on, a **density-matrix** SCF replaces charge mixing: a one-way **ADIIS → C-DIIS** pipeline (globally-convergent ADIIS far out, fast commutator-C-DIIS for the tail, history discarded at the switch) with a **κ-trust-region virtual level shift** (the shift is sized from the predicted orbital rotation `‖κ‖` in the physical-Fock MO basis, self-deactivating at convergence) and a one-way fallback to the monotone ADIIS if C-DIIS limit-cycles on a near-degenerate (metallic) system. A matrix-free **Trust-Region Augmented Hessian (TRAH)** second-order driver then **continues from the near-converged density** for a quadratically-convergent polish (the inner Newton CG uses an O(N³) `δP=C·M·Cᵀ` density response); `scf_trah` forces TRAH from the start. This robust density-matrix driver now also hosts the **multipole + exchange** SCC (v0.2.1): the experimental mDFTB2 atomic-moment Fock is rebuilt from the trial density each iteration (the moments are density-derived, so they relax with the density) with a **damped moment channel** for stability, so the multipole correction and long-range exchange converge through the same ADIIS→C-DIIS→TRAH pipeline rather than the legacy linear-mixing charge loop. (Very stiff combinations — e.g. high-order multipoles + long-range exchange on transition-metal complexes — can still fail to converge; that is a model/numerical limit, not a flag bug.) |
| Multipole electrostatics (experimental) | Parameter-free **mDFTB2** atomic dipole + quadrupole correction on top of the GFN1 monopole electrostatics (Vuong et al. 2023), **non-PBC**, self-consistent **energy + analytic gradient** (FD-verified). The multipole interaction tensors are spatial derivatives of the existing Klopman–Ohno `γ`; the moments come from the on-site AO dipole/quadrupole integrals. Off by default (≡ GFN1); enable via `ElectronicOptions::multipole`, the CLI `--multipole`, or `Gfn1NativeCalculator(..., multipole=True)`. An experimental **octupole** extension (rank-3 atomic moments, `f^(m,3)`/`f^(3,n)` interactions, self-consistent energy + analytic gradient, all FD-verified) adds the next multipole order — only nonzero for atoms with d functions (the traceless octupole vanishes for an s/p-only minimal basis); enable additionally via `multipole_octupole` / `--multipole-octupole`. A further experimental **third-order on-site** extension (`multipole_third_order` / `--multipole-third-order`) generalizes the monopole `(1/3)ΓΔq³` to the angular fluctuations, adding the parameter-free on-site charge·dipole² and charge·quad² cross terms `E³ = Σ_A [α_A Δq_A(d_A·d_A) + β_A Δq_A(Q_A:Q_A)]` (coefficients from the hardness charge-derivative); self-consistent energy + analytic gradient, FD-verified. Finally, all of these moment-based terms can draw their on-site dipole/quadrupole moment *integrals* from the node-correct **secondary** (cc-pVnZ) basis instead of the minimal primary basis (`multipole_secondary_basis` / `--multipole-secondary-basis <name|file>`, populations stay primary) for better-resolved moments; energy + analytic gradient stay consistent, FD-verified. The whole ladder is generalised to **arbitrary rank** (`multipole_order = n` / `--multipole-order n`): for `n ≥ 4` a unified parameter-free generic path self-consistently mixes the atomic moments of ranks `1..n` (the rank-`l` on-site moment integrals, the fully-symmetric interaction tensors `f^(la,lb)=∇^(la+lb)γ` reduced to their `(r+1)(r+2)/2` unique Cartesian components, and a per-element on-site moment cache), with the legacy rank-2/3 paths kept **byte-compatible** for `n ≤ 3`; energy + analytic gradient, FD-verified at `n = 4`. Layered on top, an experimental **per-rank multipole×charge cross** extension (`multipole_charge_order = [o₁,o₂,…]` / `--multipole-charge-order o1,o2,…`, where entry `l−1` is the max on-site charge order coupled to the rank-`l` 2^l-pole) Taylor-expands each on-site self-energy `½ g_l(η_A(q))(m_l·m_l)` in the breathing-radius charge dependence `η_A(q)=γ_A+2Γ_A Δq_A` — generalising `multipole_third_order` (the `l∈{1,2}`, order-3 special case it reproduces exactly) to **arbitrary rank × arbitrary charge order**. Each entry is hard-capped at the termination bound `2l+3` (above which the rank-`l` contribution is identically zero, so an out-of-range order is a **hard error**, never silently truncated); self-consistent energy + analytic gradient, FD-verified. It forces the generic path on (covering ranks `1..L`), and that generic path now also draws its on-site moment integrals from the **secondary** basis when one is supplied (previously only the legacy rank-1/2 path did). For speed the standard and cross on-site fields share a single overlap-shift assembly, and the SCC energy side uses an energy-only path that skips the Fock build. **CAMM-on-mDFTB2 (v0.4.2, experimental):** an alternative off-site model selected by `multipole_model = camm_on_mdftb2` (`--multipole-model camm_on_mdftb2`, `Gfn1NativeCalculator(..., multipole=True, multipole_model="camm_on_mdftb2")`). It keeps mDFTB2 only as the SCF/Fock skeleton + the on-site response penalty, and **replaces** the off-site Ohno multipole expansion with a **GFN2-style CAMM/AES** term — the `q–μ`, `q–Θ`, `μ–μ` interactions only (no `q–q`, which stays in the GFN1 isotropic SCC; no `μ–Θ`/`Θ–Θ`) — built on **full cumulative atomic multipole moments** `(q_A, μ_A, Θ_A)` (the `κ∈A, λ∈all` density partitioning that conserves the molecular dipole/quadrupole) and a parameter-free hardness-derived **erf charge-cloud** kernel `erf(R/σ_AB)/R`. The two off-site multipole models are never summed (no double counting): the mDFTB2 off-site term is disabled in this mode. Two calibration levers temper CAMM's over-attraction against mDFTB2's over-repulsion: the **primary** range factor `camm_damp = κ` (`--camm-damp`, scales `σ_AB = κ·σ_AB^HP` to re-balance the short range **range-selectively** while leaving the long-range `1/Rⁿ` tail unchanged) and the **secondary** amplitude `camm_aes_scale = s_AES` (`--camm-aes-scale`, a uniform AES scale that, by construction, cannot fix the contact without also weakening the correct tail). Self-consistent **energy + analytic gradient** (cumulative moments + a dedicated CAMM Fock, FD-verified `∂E/∂P` and moment conservation; the analytic gradient = off-site erf-cloud kernel force + cumulative-moment two-center integral derivatives with the `R_A` reference shifts, FD-verified vs the total-energy finite difference); non-PBC; restricted in v1 to the base dipole+quad correction in the standard SCC (octupole / generic rank / on-site cross / secondary basis / exchange / field-dipole are rejected). Off by default (`multipole_model = mdftb2`, byte-compatible). **Named presets** (`camm_preset` / `--camm-preset`) fill per-element κ (+ s_onsite) from the fits: `polar`, `halogen`, `halogen-v1`, `halogen-allgrad`, and the v0.4.4 unified **`sigma-hole`** (per-element κ **and per-element s_onsite** — halogen wants s_onsite≈0, tetrel/Si≈1; see [sigma_hole_preset.md](sigma_hole_preset.md)). CAMM is σ-hole-NCI-oriented and geometry-neutral on covalent/TM frameworks — for TM reaction energies use plain GFN1. |
| Higher-order on-site charge (experimental) | Parameter-free on-site charge expansion to **arbitrary order** `E_n = Σ_A (1/n) X_n Δq_A^n` extending GFN1's 2nd/3rd-order isotropic electrostatics. The coefficients are fixed deterministically (no fitting, no Padé) by the **Linear Breathing-Radius Model** — the on-site hardness `η_A(q)=1/R_A(q)` with `R_A` linear in charge gives the closed form `X_n = (γ_A/(n−1))(2Γ_A/γ_A)^(n−2)` from the existing hardness `γ_A` and Hubbard derivative `Γ_A` (reduces to the 2nd/3rd-order GFN1 terms and `X_4 = (4/3)Γ²/γ`); the order-4 quartic stays convex (bounded, no spurious inflection). **Non-PBC**, self-consistent energy + analytic gradient (rides the SCC charges; FD-verified at n=4 and n=6). Default `charge_order = 3` ≡ stock GFN1; raise via `ElectronicOptions::charge_order`, the CLI `--charge-order N`, or `Gfn1NativeCalculator(..., charge_order=N)`. |
| Range-separated Fock exchange (experimental) | Parameter-free **long-range exact (Fock) exchange** on top of the GFN1 mean field, **non-PBC**, **off by default** (≡ stock GFN1), self-consistent energy + analytic gradient, FD-gated. Two layers: **MFX** (`lr_exchange` / `--lr-exchange`) is the Mulliken long-range exchange of LC-DFTB (Niehaus & Della Sala; Lutsker, Aradi & Niehaus 2015), `E_x = ½Tr[ΔP·K[ΔP]]` with `K[ΔP]_{μν}=−⅛Σ ΔP_{σλ}S_{μσ}S_{νλ}(γ^lr_{μν}+γ^lr_{μλ}+γ^lr_{σν}+γ^lr_{σλ})` over the density fluctuation `ΔP=P−P0` (neutral-atom reference), assembled by symmetric **GEMM** factorisation (no AO four-index loop). **OFX** (`onsite_exchange` / `--onsite-exchange`, layered on MFX) upgrades the *same-atom* exchange from the Mulliken approximation to the **exact one-center two-electron integrals** via the difference kernel `K_OFX = K_onsite,refined^lr − K_onsite,Mulliken^lr` (no double count) — real STO-nG one-center ERIs built once per element (geometry-independent, cached). The long-range kernel is a hardness-derived Gaussian charge-cloud `γ^lr=erf(R/τ)/R` (finite at `R=0`), with the crossover `ω` from one of several **parameter-free schemes** (`HardnessPairwise` `ω_A=η_A` default; `Fixed`). An experimental **dynamic (geometry-adaptive) range separation** (`dynamic_omega` / `--dynamic-omega`, the `LocalGeometry` scheme) sets `ω_A=η_A/s_A` with the parameter-free size factor `s_A=(1+CN_A)^(−1/3)` from the **GFN1-Hamiltonian coordination number** (a more-coordinated atom screens at shorter range; reduces to `HardnessPairwise` at `CN=0`), with the full **analytic `∂ω/∂R` reorganisation force** for both MFX and OFX (FD-gated). The on-site ERI screening is factored as `(μκ|νλ)^lr(ω)=Σ_k c_k β^{(2k+1)/2}` (`β=ω²/(ω²+α)`), so the expensive per-element tensor is built **once per process** as an ω-independent skeleton (memory-efficient: `(p,q)`-grouped, even-order only) and re-evaluated cheaply at each atom's `ω` — a dynamic-ω optimisation never rebuilds the d/f-element ERIs per step. Convergence uses the density-matrix DIIS / TRAH drivers above. *Note:* full MFX/OFX on a small-gap/metallic system should be paired with `charge_order = 4` — the convex quartic bounds the otherwise-unbounded cubic so the long-range exchange does not collapse the density (e.g. it makes dppf-PdCl₂ converge to a physical state). |
| Excited states | **TD-GFN1 (TDA)** in the Niehaus transition-charge TD-DFTB response model (singlet/triplet, Mulliken oscillator strengths): non-periodic (`solve_tda`), Gamma-point periodic (`solve_tda_pbc_gamma`), and off-Gamma **k-point** periodic (`solve_tda_kpoint`, reduces to the Gamma path at a single point), plus excited-state **gradients**, fully **analytic** and FD-verified: non-periodic and Γ-point `solve_tda_gradient_analytic` and k-mesh `solve_tda_kpoint_gradient_analytic` (direct-CPHF excitation-energy gradient; gauge-invariant via the natural CPHF gauge — the max-AO phase fixing is never differentiated). The production selector `solve_tda_gradient_method` (`TdaGradientMethod`) also offers `SemiNumerical` (`solve_tda_gradient_seminumerical`, default: analytic ground gradient + central FD of the frozen-amplitude excitation energy) and `FiniteDifference` (`solve_tda_gradient`, full re-diagonalised, root-tracked). **Two v0.5.0 correctness fixes** (both silent, both invisible on the dark states the previous gates used): (1) the missing **on-site third-order kernel derivative** `c Σ_A (∂³E_onsite/∂q³)(dq_A/dR) P_A²` — the DFTB3 on-site block of the response kernel depends on the ground-state charge, so it carries a nuclear chain the geometric `dγ/dR` helper cannot see (jittered-formaldehyde S3: constant `3.35e-6` Ha/bohr residual, ladder ratio 1.03 → `1.45e-6 → 3.62e-7`, ratio 4.00); (2) the **MO phase gauge** of the frozen-amplitude excitation energy, which the eigensolver leaves arbitrary and discontinuous in the geometry — the `SemiNumerical` default diverged as `1/h` for any bright state (water S3: `14.3` Ha/bohr at `h = 1e-3` → `6.6e-7`). `tda_frozen_excitation_energy` therefore now takes a `reference: Option<&ElectronicResult>`. Full working equations, per-root gate numbers and limitations in [td.md](td.md). |
| Spin polarization (spGFN1) | **Collinear spin-polarized GFN1** ("spGFN1"): adds the spin-DFTB spin-polarization energy `E_spin = ½ Σ_A Σ_{l,l'} W_{A,ll'} m_{A,l} m_{A,l'}` (shell magnetizations `m_{A,l}=n^α−n^β`) on top of the **unchanged** GFN1 model, with the per-spin Fock `F^{α/β}=H0−½v^c S ∓½V^s S` and `V^s_{A,l}=Σ_{l'} W_{A,ll'} m_{A,l'}`. **Non-PBC, energy + analytic forces** (overlap-Pulay spin term, FD-gated on CH₃ and O₂; `W` is a constant on-site quantity → no `∂W/∂R`). Off by default; enable with `spin_polarization` / `--spinpol` / `Gfn1NativeCalculator(..., spin_polarization=True)` (+ a `multiplicity`). Only affects **open-shell** configurations — a closed-shell singlet is **byte-identical** to plain GFN1 (delegated to the restricted path). The atomic spin constants `W` are transcribed **byte-exact** from tblite `data/spin.f90` (`spin_constants(6,86)`, LGPL-3.0-or-later, compatible with this GPL-3.0-or-later crate; verbatim snapshot + provenance under `third_party/tblite/`, also in `THIRD_PARTY_NOTICES.md`). v1 is the bare GFN1 model: combining with the experimental multipole / CAMM / Fock-exchange / D4 / external-field paths is rejected (not yet derived against them). |
| Magnetic field | **Closed-shell magnetic SCC** in London atomic orbitals — **GFN1-xTB-M0** (single basis) and **GFN1-xTB-M1** (node-correct dual-basis kinetic-energy correction); Cheng & Wibowo-Teale: complex `H0(B)`/`S(B)` solved with the complex Hermitian eigensolver, gauge-origin invariant, non-periodic (`run_magnetic_scc` / `run_magnetic_scc_m1`). **Magnetizability** — both the finite-field reference (`magnetizability_isotropic`, eq 26) and the **analytic McWeeny density-matrix CP-SCC response** (`magnetizability_isotropic_analytic` / `magnetizability_diagonal_analytic` / full symmetric tensor `magnetizability_tensor_analytic`; one SCC + analytic response instead of `6+1` finite-field SCCs, FD-verified), in 10⁻³⁰ J/T². | Third derivative (cubic force constants) | Non-PBC nuclear `T_abc = ∂³E/∂R_a∂R_b∂R_c`, three routes. **(1) Strict closed form** (`third_derivative_analytic` + `_dense`/`_vector`/`_block`): the 2n+1 rule with **no finite differences** (`D_c H_frozen + D_c R_static + D_c R_orbital`, analytic Z-vector). Packed `SymmetricFourth` storage with `contract_last`/`contract_last2`/`contract_vvvv`/`block`. `directional_fourth_seminumerical` (central FD of the analytic third) is the verification reference and the smeared-occupation fallback. **The 30-DOF cap no longer constrains the directional quartic** — D3/halogen feed their fourth derivative through 1-D jets along the requested direction, so `directional_fourth_derivative` scales with `nat`, not `ndof⁵` (`tests/fourth_derivative_nocap.rs` gates a 36-DOF halogen complex; 45 DOF runs in about a minute). `MAX_FOURTH_DERIVATIVE_NDOF = 30` still bounds the **full-tensor** `dispersion_fourth_derivative` / `halogen_fourth_derivative` entry points and the `n⁴`-expanded front ends. See [derivatives.md](derivatives.md#4-fourth-derivative-quartic-force-constants-fc4). |
| Charge-space response solver | `response::charge_space` (v0.5.0): the SCC couples the density only through the `nsh` Mulliken shell charges, so every response splits into a bare spectral part plus dielectric screening. `ChargeSpaceContext` builds the static susceptibility `χ⁰`, LU-factors `(I − χ⁰K)` **once**, and serves every right-hand side from it — all `3N` first-order geometric perturbations (`solve_first_order` / `first_order_field`) and all `O((3N)²)` second-order ones (`solve_second_order` / `second_order_field`).
